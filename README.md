# منصة لجنة المسؤولية المجتمعية · سنكري القابضة

المنصة تعمل على **Render**، وتحفظ بياناتها في قاعدة **Neon** (Postgres مجانية بلا انتهاء). البيانات والحسابات مشتركة بين الجميع ومن أي جهاز.

## الخطوات (مرة واحدة)

### 1. Neon: قاعدة البيانات
1. ادخل إلى **neon.tech** وأنشئ حساباً (يمكن بحساب GitHub).
2. **Create project**، والمنطقة **AWS Europe Central (Frankfurt)**.
3. من **Connect** انسخ **Connection string**، وهو يبدأ بـ `postgresql://` وينتهي بـ `?sslmode=require`.
4. لا حاجة لإنشاء جداول؛ المنصة تنشئها تلقائياً.

### 2. GitHub: المستودع
ارفع **كل الملفات** إلى جذر مستودع جديد (Upload files).

### 3. Render: الخادم
1. ادخل إلى **render.com** بحساب GitHub، ثم **New +** ← **Web Service**، واختر المستودع.
2. **Language: Docker**، **Instance Type: Free**.
3. في **Environment Variables** أضف:
   - `DATABASE_URL` = رابط Neon
   - `SESSION_SECRET` = أي نص طويل عشوائي
4. **Create Web Service**. بعد انتهاء البناء يظهر الرابط `https://….onrender.com`.

### 4. أول دخول
`eyad` / `admin1234`، ثم اختر كلمة مرور جديدة. أضف الأشخاص من زر **الأدوار**.

## ملاحظات
- **التأكد من الحفظ الدائم:** في سجل Render (Logs) يجب أن يظهر `storage: postgres`. إذا ظهر `storage: file` فالمتغير `DATABASE_URL` غير مضبوط، والبيانات ستضيع.
- **بطء أول فتح:** الخطة المجانية في Render تنام بعد 15 دقيقة بلا استخدام، فيتأخر أول فتح حوالي 50 ثانية. البيانات لا تتأثر.
- **نقل بيانات سابقة:** من النسخة القديمة اختر قائمة اسمك ← **نسخة احتياطية** ← **نسخ كنص**. ثم في المنصة الجديدة اختر **استيراد نسخة احتياطية** ← الصق ← **دمج مع الموجود**.
- **النسخ الاحتياطي:** يحفظ الخادم نسخة يومية في جدول `csr_backup`، وتظهر في Neon من **Tables**.
- **الحماية:** كلمات المرور مشفّرة على الخادم، ولا تصل إلى المتصفح.
